Driving the dashboard

  
Zoom

  
Drag a rectangle on the chart to zoom into any region - dense clusters become readable. A thin horizontal or vertical band zooms just the axis it spans. Double-click the chart, press Esc, or hit "reset zoom" to zoom back out. Zoom holds while data refreshes; changing an axis resets it. Double-clicking the detail panel closes it.

  
Filters

  
    
    
  • src / dst contains - keep matching text (substring).
    • 
    
  • src / dst not - hide matching text.
    • 
    
  • ports are / ports not - dest-port lists, e.g. 443, 53, 1000-2000. "ports not" shows everything except those ports.
    • 
    
  • direction - tick any combination: e.g. untick out and other for internal and inbound only.
    • 
    
  • from / to - time window; min count - busiest tallies only.
    • 
  

  
Encodings

  
X / Y position, color and size can each be set to any aspect: time, source, destination, port, protocol, severity, direction, counts. Size also offers per-group aggregates - e.g. "distinct ports per group" sizes each dot by how many different services its device talks to (grouping follows the color variable, then the categorical axis).

  
Points

  
Hover a dot for a summary; click it for the full tally entry. Each dot is one known occurrence (tallies) or one raw record.

  
Refresh

  
Data refetches every 30 s (toggle "auto 30s"). Colors and zoom stay stable; the time window slides forward. "refresh" refits the axes; "reset all" restores defaults.
